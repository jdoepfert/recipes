# Rezepte

Eine Sammlung von Rezepten, veröffentlicht als Webseite.

🌐 **Zur Webseite mit allen Rezepten:** https://jdoepfert.github.io/recipes/

Die Seite wird bei jedem Push auf `master` automatisch über GitHub Actions gebaut und auf GitHub Pages veröffentlicht (siehe [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).
